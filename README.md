# 인성+코딩 워크북 (Character-Coding-Workbook)

본 저장소는 아동·청소년이 **12가지 핵심 인성 덕목(존중·우정·공감·도전·감사·절제·인내·정직·자존감·책임·협동·사랑)**을 자기탐색 질문으로 성찰하고, 손그림을 찍어 모바일 게임으로 플레이하는 **픽시아케이드(Pixicade)** 창작 미션으로 연결하는 **12차시 인성+코딩 워크북 자료실**입니다.

> **과정 구분 안내 (`웹 15회 · 워크북 12회 · 현장 15주` 분리 기준 및 Zero-PII 원칙)**
> - **인성+코딩 워크북 (본 저장소)**: 12가지 인성 가치 카드(`01 존중` ~ `12 사랑`) 중심의 **12차시** 워크북 과정
> - **꿈스케치 LifeWork 웹 플랫폼 (`vovis7-an/pixicade-class`)**: 별칭·버킷리스트·동사·강점·라이프워크 문장·Dream Tree로 이어지는 **15회차** 웹 워크시트 과정
> - **현장 학기 운영**: 기관 일정에 맞춘 **15주** 현장 수업 운영
> - **Zero-PII 원칙**: 학생 실명·연락처·학교명 등 민감 개인정보를 저장하거나 외부로 전송하지 않고 별칭(Nickname)과 탐색 키워드만 기록합니다.

## 12차시 인성 덕목 × 픽시아케이드 창작 커리큘럼

| 차시 | 인성 덕목 (영문) | 픽시아케이드(Pixicade) 창작·게임화 미션 |
|:---:|:---:|---|
| 01 | 존중 (respect) | 다름을 인정하고 경청하는 캐릭터 대화·시작 섬 도안 |
| 02 | 우정 (friendship) | 친구와 함께 통과하는 협동 목표 오브젝트 설계 |
| 03 | 공감 (empathy) | 상대의 감정 신호를 읽고 반응하는 회복 아이템 매핑 |
| 04 | 도전 (challenge) | 가슴 뛰는 신호등 미로와 새 경로 탐색 액션 설계 |
| 05 | 감사 (gratitude) | 일상의 고마운 단서를 모으는 보물섬 스테이지 |
| 06 | 절제 (restraint) | 규칙과 균형을 지켜 함정을 피하는 컨트롤 미션 |
| 07 | 인내 (patience) | 반복 시도와 디버깅으로 완주하는 3홀 코스 |
| 08 | 정직 (honesty) | 진실한 선택으로 열리는 오프닝·엔딩 게이트 |
| 09 | 자존감 (self-esteem) | 나의 강점과 고유한 빛을 표현하는 마스터피스 |
| 10 | 책임 (responsibility) | 맡은 역할을 끝까지 수행하는 조력자 NPC 미션 |
| 11 | 협동 (cooperation) | 서로의 강점을 연결해 퍼즐을 푸는 팀워크 스테이지 |
| 12 | 사랑 (love) | 배려와 나눔의 메시지를 전하는 학급 전람회 작품 |
