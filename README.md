# Character-Coding-Workbook (성품·코딩 12회차 통합 워크북 표준 스키마)

본 저장소는 **꿈스케치 LifeWork (`pixicade-class`)**, **꿈스케치 아일랜드 (`dream-sketch-game`)**, **미래준비청년 포트폴리오 (`dreamsketch-portfolio`)** 간 12회차 성품·자기탐색·게임 설계 데이터를 호환하기 위한 표준 커리큘럼 및 JSON 브릿지 명세서입니다.

## 1. 12회차 성품·코딩 워크북 커리큘럼 구조

| 회차 | 핵심 성품 가치 | 자기탐색 활동 | Pixicade 코딩/표현 미션 |
| :--- | :--- | :--- | :--- |
| **01회** | 호기심 (Curiosity) | 나를 움직이는 첫 질문 찾기 | 아바타와 시작 섬 도안 스케치 |
| **02회** | 주도성 (Initiative) | 버킷리스트 스타터 3선 | 목표 오브젝트 배치와 충돌 규칙 |
| **03회** | 감사 (Gratitude) | 행복 신호와 몰입 순간 기록 | 에너지 아이템과 회복 블록 설계 |
| **04회** | 열정 (Enthusiasm) | 가슴 뛰는 동사(Green Signal) 분류 | 캐릭터 이동·점프·액션 동사 매핑 |
| **05회** | 끈기 (Perseverance) | 열정 키워드와 반복 성공 근거 | 난이도 있는 장애물과 재도전 루프 |
| **06회** | 창의성 (Creativity) | 나만의 4대 표현 방식 탐색 | 기발한 기믹(포털/스위치) 스테이지 제작 |
| **07회** | 성실 (Diligence) | 강점 카드 발견과 동료 피드백 | 친구 플레이테스트 및 버그 디버깅 |
| **08회** | 소명 (Purpose) | 라이프워크(LifeWork) 한 문장 선언 | 게임 오프닝/엔딩 스토리보드 완성 |
| **09회** | 겸손·배움 (Humility) | 닮고 싶은 롤모델 태도 탐색 | 협력 NPC 대화 및 힌트 시스템 구현 |
| **10회** | 지혜 (Wisdom) | 내 삶을 바꾼 책 속 한 문장 | 퀴즈·단서 해독 게이트 설계 |
| **11회** | 용기 (Courage) | 직접 가보고 확인할 실제 현장 | 최종 보스/미션 클리어 스테이지 완성 |
| **12회** | 책임·나눔 (Stewardship) | 2031 미래 비전과 다음 주 3대 실천 | A3 미래신문 2면 발행 및 전람회 공유 |

## 2. 플랫폼 간 연동 스키마 (`workbook-curriculum.json`)
- 개인 식별정보(실명·연락처·상세 주소)를 배제한 **Zero-PII 원칙**을 준수합니다.
- `dreamsketch-lifework-result` 포맷과 1:1 호환되어 포트폴리오 작성기(`dreamsketch-portfolio`)에서 즉시 초안으로 변환됩니다.
